A living deep-sea tank on your screen

Phylotank is an artificial-life fishtank. Glowing creatures grow their bodies from DNA, think with evolved neural networks and pass every trait on to their young, even how fast they mutate. Nobody scripts what happens: you watch evolution do it.

This is the real Phylotank simulation, running entirely in your browser in a background worker. Nothing is sent anywhere. The project is early: today the tank holds glowing plankton drifting in a slow current, and the first creatures arrive with version 0.1, "Glass tank".

The tank respects your system's reduced-motion setting: with it on, the demo only starts when you press Start. All Phylotank views cap how fast lights can pulse and how quickly the screen can brighten, so they never flash.

What it is

  • Bodies grown from DNA

    Every creature unfolds from a genome of parts and growth rules: segments, fins, jaws, eyes, light organs and tentacles. Swimming is real physics in water, so a body that works is one that evolution found.

  • Brains that evolve

    Each creature senses light, scent, touch and its own hunger, and acts through a neural network that is inherited and mutated like any other trait.

  • A food web that balances itself

    Light grows plankton, grazers eat plankton, predators eat grazers, and scavengers and plankton recycle the dead. Mass and energy are conserved, so a tank cannot cheat.

  • You are the god of the tank

    Design creatures and release them, then throw meteors, plagues and cold snaps at the tank and watch it adapt. Captured and designed creatures travel as small files or text strings.

  • One world, four views

    A calm live wallpaper, a screensaver with a documentary camera, a TV view, and a god window for designing and meddling. They all show the same persistent world.

  • Private and gentle

    No accounts, no servers, no tracking. The tank runs on your own computer, is gentle on the battery when it is your wallpaper, and never flashes.

Download

Every download is on the project's GitHub releases page, with a SHA256SUMS.txt file to check it against.

  • In a browser

    phylotank-web-<version>.zip

    The tank on its own, no install. Unzip it, serve the folder with any small web server and open index.html. Or just use the demo above.

  • Live wallpaper

    phylotank-lively-<version>.zip

    For Lively Wallpaper on Windows: drop the zip onto Lively and apply it to your monitors.

  • Windows: screensaver and world

    phylotank-windows-<version>.zip

    The tray app, the screensaver and the persistent world that the wallpaper, screensaver and TV all show. Windows 10 or 11, 64-bit, no admin rights needed.

Latest release All releases

Not code-signed yet. Windows SmartScreen will warn the first time you run the Windows build: choose "More info", then "Run anyway". Check the file against SHA256SUMS.txt first if you like. Free open-source code signing is planned.

Install

  1. Pick a download from the list above. If you are not sure, start with the Windows zip: it includes everything.
  2. Unzip it and run install.cmd. It installs for your user only and adds Phylotank to the tray.
  3. Choose the screensaver in Windows' screensaver settings, and add the Lively package if you want the wallpaper.
  4. Open the god window from the tray icon to watch, design and meddle.

The full install guide covers every step with the wallpaper, the screensaver, casting to a TV, updating, uninstalling and troubleshooting.

Share a creature

Creatures travel as a .ptkg file or a short PTK1. text string, and as a link to this site's share page. The creature rides in the part of the link after the #, which browsers never send to a server, so sharing needs no account and no server at all.
